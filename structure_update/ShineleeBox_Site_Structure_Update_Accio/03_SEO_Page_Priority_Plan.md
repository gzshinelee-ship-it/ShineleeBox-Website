## Product Page SEO Rule
Every product page should include:

- H1 product name
- 80–120 word intro
- Key Features in text
- Best For in text
- Custom Options in text
- Manufacturing Support by ShineleeBox
- FAQ
- Inquiry CTA

Avoid icon-only feature sections because search engines need readable text.
