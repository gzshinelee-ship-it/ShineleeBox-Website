## Positioning Logic

ShineleeBox should use three main navigation pillars:

1. Products — by box type and packaging structure.
2. Applications — by what the customer needs to package or the industry use case.
3. Holiday & Occasions — by seasonal campaign, celebration, or gifting occasion.

Do not use Industry as a main top-level menu. Use “Applications” as the top-level menu because it is more buyer-friendly and more flexible for SEO. Inside application pages, it is fine to use the heading “Industries We Serve”.
