  list_github_repos
    List GitHub repositories accessible to the authenticated user,
    including **private repos** that are invisible without login.
    
    By default, lists repos owned by / accessible to the authenticated user
    (``GET /user/repos``). When ``organization`` is supplied, the tool
    switches to listing repos under that organization (``GET /orgs/{org}/repos``);
    private repos the authenticated user has access to within the org are
    included.
    
    Note: this tool intentionally does NOT accept a ``username`` filter.
    GitHub's ``GET /users/{username}/repos`` endpoint only ever returns
    public repositories — even when authenticated and even when the
    username matches the caller — so exposing it here would mislead users
    into thinking private repos can be listed by username. To see your
    own private repos, simply omit ``organization``.
    
    Call this tool when the user asks:
    - "What repos do I have?"
    - "Show me my private repositories"
    - "List my recently updated projects"
    - "Show all repositories under the alibaba organization"
    
    Args:
        user_login: GitHub username whose credential to use. Leave empty to auto-detect.
        visibility: Filter — "all" (default), "public", or "private".
            Only applies when listing the authenticated user's own repos
            (i.e. ``organization`` is not provided).
        sort: Sort field — "created", "updated" (default), "pushed", or "full_name".
        per_page: Results per page, 1–100. Default 20.
        page: Page number starting at 1.
        organization: If provided, list repositories under this GitHub
            organization (``GET /orgs/{org}/repos``).
    
    Returns:
        On success — JSON ``{ repos: [...], pagination: {...}, user_login,
        scope: {...} }``. ``scope`` describes which listing was performed:
        ``{"type": "self" | "org", "target": <name or null>}``.
        Each repo: full_name, description, html_url, private, language,
        stargazers_count, forks_count, updated_at, default_branch.
    
        On failure — single-line error with action suggestion.
    meta: toolkit=github, toolkit_service=repos
      - user_login (string)
      - visibility (string)
      - sort (string)
      - per_page (integer)
      - page (integer)
      - organization (string)

    STEP 1 of 2 in the supplier verification flow. Use this tool when the user
    wants to generate a supplier verification report. Call this FIRST, then pass
    the returned company_id values to `supplier_verification_detail`.
    
    Difference from `supplier_verification_detail`:
      - This tool (recall) INPUT is a fuzzy company name or storefront URL and
        OUTPUT is a LIST of candidate suppliers (each with a company_id) for the
        user to pick from. It performs a search/match and has no report detail.
      - `supplier_verification_detail` INPUT is exact company_id(s) obtained from
        this tool and OUTPUT is the full verification report detail for them.
    
    Args:
        supplier_name: The supplier/company name or Alibaba storefront URL to look up.
                       Example: "Qingdao Etrip Smart Home Co., Ltd." or
                       "https://cnetriphome.en.alibaba.com/contactinfo.html".
                       URLs are automatically normalized to extract the company token.
        top_k: Max number of candidates to recall (default 50, range 1-100).
    
    Returns:
        JSON with payload.candidates (list of matched suppliers with company_id,
        company_name_en, company_name_cn, company_minisite_url, seller_score).
        Use company_id from candidates to call supplier_verification_detail.
    meta: toolkit=alibaba, toolkit_service=supplier-verification-report
      - supplier_name (string) — The supplier/company name or Alibaba storefront URL to look up. Example: "Qingdao Etrip Smart Home Co., Ltd." or "https://cnetriphome.en.alibaba.com/contactinfo.html". URLs are automatically normalized to extract the company token.
      - top_k (integer) — Max number of candidate suppliers to recall. Range 1-100, default 50. Example: 10.
