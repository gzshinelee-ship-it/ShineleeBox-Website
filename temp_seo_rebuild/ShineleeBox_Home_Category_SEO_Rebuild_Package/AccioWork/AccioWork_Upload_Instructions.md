# AccioWork Upload / Deployment Instructions

Please deploy this ShineleeBox Home + Category SEO rebuild package.

## Important
This is a visual and SEO cleanup package. Do not randomly redesign the entire brand. Follow the provided menu, color palette, page structure and SEO rules.

## Step 1: Update Global Header and Footer
Use the menu structure in `02_Menu_Framework.md`.
Make sure all pages use the same shared header/footer component.

## Step 2: Fix Home Page
Use `01_Home_Page_Rebuild.md`.
Make the hero headline and subheadline real HTML text, not only text inside an image.
Fix overlapping text and keep a premium Western minimalist layout.

## Step 3: Apply Style System
Use `03_UI_Style_Guide.md`.
Fix low-contrast text, especially on Beauty / Perfume application pages.
Use overlays or left text panels when banners use product images.

## Step 4: Optimize Category Pages
Use `04_Category_Page_Optimization.md`.
Update banners, intro text, CTA and FAQ blocks.
Clean product/category mismatches.

## Step 5: Product Checks
Use `Product_Cleanup_Plan.csv`.
For products with insufficient images, add at least two additional images:
- structure / opening view
- detail / insert / finish close-up
- optional lifestyle scene

## Step 6: SEO
Use `Page_SEO_Table.csv`.
Update each page’s SEO title, meta description, H1, and focus keywords.
