# Category Page Optimization Rules

## Standard Category Page Structure

1. SEO Hero Banner
2. Short B2B Intro
3. Product Grid
4. Structure / Custom Options
5. Applications
6. Why ShineleeBox
7. FAQ
8. CTA

## Hero Layout
- Left 40%: H1, short SEO intro, CTA
- Right 60%: product image or clean product collage
- Ensure text contrast is high and readable.
- Use HTML text for H1 and intro.

## Category Cleanup Rules
- Round Gift Boxes should only show round or cylindrical boxes.
- Suitcase Gift Boxes should only show true suitcase-style boxes.
- Electronics & Premium Packaging should show video, music, LED and interactive packaging only.
- Religious products should not appear under Round Gift Boxes unless the physical structure is truly round.
