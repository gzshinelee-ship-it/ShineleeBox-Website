# ShineleeBox UI Style Guide

## Visual Direction
Premium Western minimalist B2B packaging website. Clean, warm, elegant, trustworthy and not overly colorful.

## Color Palette

- Warm Ivory Background: #F7F3EC
- Card Background: #FFFFFF
- Charcoal Text: #1F1F1F
- Secondary Text: #5F5A52
- Muted Text: #8A8175
- Soft Border: #E5DDD0
- Champagne Gold Accent: #C6A15B
- Deep Burgundy CTA: #5A1F2B
- Forest Green Secondary Accent: #1F3A2E
- Dark Section: #171717

## Color Usage
- 70% warm ivory / white
- 20% charcoal / dark text
- 7% champagne gold accent
- 3% deep burgundy / forest green

## Typography
- Heading font: Playfair Display or similar luxury serif
- Body font: Inter or similar clean sans-serif
- Button font: Inter SemiBold

## Button Style
Primary CTA:
- Background: #5A1F2B
- Text: #FFFFFF
- Hover: #C6A15B

Secondary CTA:
- Transparent background
- Border: #C6A15B
- Text: #1F1F1F

## Readability Fixes
- Do not place light gold or gray text directly on bright product images.
- Use a dark overlay or left-side solid panel for banner text.
- Avoid text overlap by increasing hero height and separating title, subtitle and buttons.
- Keep all key SEO text as HTML, not only inside images.
