### Hero Design Rules
- Use real HTML text for H1 and subheadline. Do not put key SEO text only inside the banner image.
- Use warm ivory background: #F7F3EC.
- Use charcoal text: #1F1F1F.
- Use deep burgundy CTA: #5A1F2B.
- Use champagne gold accent: #C6A15B.
- Avoid overlapping text. Hero height should be responsive and image should not cover text.
